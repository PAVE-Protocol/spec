# PAVE Publication History

## Earlier Public Materials

Earlier public PAVE materials included a Generative Human Intelligence (GHI) elicitation schema and accompanying technical notes.

These materials were published in the original source repository but have since been retired. They are not included in this repository or its Git history and should not be used as current implementation guidance.

Their retirement does not change the terms under which they were originally distributed.

## Current Documentation

PAVE's current public documentation describes the protocol's purpose, architecture, terminology, and proposed applications.

Start with the [PAVE overview](README.md) to explore the current documentation.
